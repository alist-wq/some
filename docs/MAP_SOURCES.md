# Map source

The initial approved regional packages use the OpenFreeMap Liberty style at
`https://tiles.openfreemap.org/styles/liberty`. OpenFreeMap documents MapLibre Native use,
public-instance availability, and required attribution: “OpenFreeMap © OpenMapTiles Data from
OpenStreetMap.” OpenFreeMap is MIT licensed; underlying OpenStreetMap data remains subject to
ODbL attribution requirements. See https://openfreemap.org/ and https://openfreemap.org/tos/.

The app only preloads a region after explicit confirmation. The public source has no SLA; a
future production rollout should move to an approved self-hosted or contracted source before
large-scale distribution.
